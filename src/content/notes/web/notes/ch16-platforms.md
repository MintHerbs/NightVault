# Chapter 16: Platforms

*Week 16 · 2+1 hrs*

Two platforms dominate. Each has its own store, review process, and expectations.

|  | iOS | Android |
| --- | --- | --- |
| Store | App Store | Google Play |
| Language | Swift | Kotlin |
| Review process | Manual human review, stricter, can take days | Mostly automated, faster, still has policy checks |
| Distribution | Store only (mostly) | Store, or install the file directly (APK) |

## What this means for you

* Every app update goes through a review queue, budget time for it, don't plan a launch for the same day you submit.
* Both platforms have strict rules on data privacy and permissions, asking for a permission (like location) you don't clearly use gets apps rejected.
* Cross-platform tools (Chapter 15) still ultimately compile down to these two native platforms and their stores.
